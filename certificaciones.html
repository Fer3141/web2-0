Certificaciones para DevSecOps

DevSecOps es un rol que cruza tres mundos: desarrollo, operaciones / cloud y seguridad. No hay una única certificación "de DevSecOps" que te habilite; lo normal es apilar varias de cada área. Cada enlace va a la página oficial de la certificación.

¿Hace falta certificarse?

No en el sentido estricto: nadie te pide un papel para trabajar de esto. Sirven para dos cosas concretas:

  • Pasar filtros de RR.HH. y llegar a la entrevista técnica, sobre todo en empresas grandes o consultoras.
  • Estudiar con un temario ordenado en vez de saltar de tutorial en tutorial.

Lo que te contratan es la habilidad práctica con pipelines, infra como código y herramientas de seguridad (ver la página de DevSecOps).

Con presupuesto ajustado

Si no podés pagar muchas, este es el orden por relación valor / precio. Los precios son aproximados y del examen (sin cursos), en dólares.

Gratis — hacé esto sí o sí, antes que cualquier examen

  • PortSwigger Web Security Academy — labs de seguridad web.
  • OWASP Top 10 y ASVS.
  • Un pipeline propio en GitHub Actions con SAST + SCA + escaneo de secretos. Esto lo mostrás en la entrevista y vale más que un título.

Prioridad 1 — baratas y con buena señal (~USD 170 las dos)

  • HashiCorp Terraform Associate — ~USD 70. Infra como código; universal y muy pedida.
  • Burp Suite Certified Practitioner (BSCP) — ~USD 99. Práctica; la parte "Sec" sin gastar de más.

Prioridad 2 — una sola, según tu objetivo

  • Si apuntás a Azure: Microsoft AZ-500 — ~USD 165. La cert de seguridad cloud más barata.
  • Si apuntás a AWS: AWS Security – Specialty — ~USD 300.
  • Si te falta la parte de operaciones: CKA — ~USD 300–450 (mirá ofertas de la Linux Foundation).

Dejá para después (o que las pague la empresa)

  • CompTIA Security+ — ~USD 400. Solo si un filtro de RR.HH. te la exige; si no, estudiá los fundamentos por tu cuenta.
  • CKS — ~USD 450 y necesita CKA vigente (unos USD 750–900 en total).
  • Certified DevSecOps Professional (CDP) — buenísima, pero se compra con curso.
  • SANS SEC540 / GIAC GCSA — USD 8k+. Casi siempre la paga el empleador.

Si solo podés pagar una ahora: Terraform Associate (~USD 70). Es la más barata, no caduca el temario tan rápido y aparece en casi todas las ofertas de DevOps / DevSecOps.

Ruta corta recomendada

Si tuviera que elegir un solo camino, sería este orden:

  1. CompTIA Security+ — fundamentos de seguridad.
  2. HashiCorp Terraform Associate — infraestructura como código.
  3. Microsoft AZ-500 o AWS Security Specialty — seguridad en la nube.
  4. CKS — seguridad en Kubernetes (requiere CKA vigente).
  5. Certified DevSecOps Professional (CDP) — el pegamento entre todo lo anterior.

1. Base / fundamentos

Certificación Qué acredita Notas
CompTIA Security+ Fundamentos de seguridad: amenazas, criptografía, IAM, redes. El estándar de entrada. Multiple choice, sin prerrequisitos.
HashiCorp Terraform Associate Infraestructura como código con Terraform / OpenTofu. Barata y muy práctica. Examen online de ~1 h.
Linux Foundation Certified SysAdmin (LFCS) Administración de Linux desde la terminal. Opcional si ya te movés bien en Linux. Examen práctico.
GIAC GSEC Seguridad general, más profunda que Security+. Cara (vía cursos SANS). Suele pagarla la empresa.

2. Cloud

Elegí un proveedor según el mercado al que apuntes y hacé la ruta base → seguridad. Los conceptos se trasladan.

AWS

Certificación Qué acredita Notas
AWS Solutions Architect Associate Diseñar arquitecturas en AWS. Buen punto de partida en AWS.
AWS Security – Specialty IAM, cifrado, detección, respuesta a incidentes en AWS. La más relevante para el "Sec" en AWS.
AWS DevOps Engineer – Professional CI/CD, IaC y automatización en AWS. Nivel profesional; conviene tener una Associate antes.

Azure

Certificación Qué acredita Notas
Microsoft AZ-104 (Azure Administrator) Administración de recursos en Azure. Base para AZ-500.
Microsoft AZ-500 (Azure Security Engineer) Identidad, protección de plataforma, datos y operaciones de seguridad. La opción "Sec" en Azure.
Microsoft AZ-400 (DevOps Engineer Expert) CI/CD, IaC y prácticas DevOps con Azure DevOps / GitHub. Requiere AZ-104 o AZ-204 aprobada.

Google Cloud

Certificación Qué acredita Notas
Associate Cloud Engineer Desplegar y operar en GCP. Punto de partida en GCP.
Professional Cloud Security Engineer IAM, red segura, protección de datos y cumplimiento en GCP. La opción "Sec" en Google Cloud.

3. Contenedores y Kubernetes

Certificación Qué acredita Notas
KCNA (Kubernetes and Cloud Native Associate) Conceptos de Kubernetes y ecosistema cloud native. Entrada teórica; opcional si vas directo a CKA.
CKA (Certified Kubernetes Administrator) Operar un clúster de Kubernetes. Prerrequisito de facto y de CKS. Examen práctico en terminal.
CKS (Certified Kubernetes Security Specialist) Endurecer clústeres: RBAC, NetworkPolicies, admission control, runtime. La más "DevSecOps" del ecosistema CNCF. Requiere CKA vigente.

4. DevSecOps específico

Certificación Qué acredita Notas
Certified DevSecOps Professional (CDP) Integrar SAST / DAST / SCA / secretos en un pipeline real. Practical DevSecOps. Examen hands-on de 12 h. Precio accesible.
Certified DevSecOps Expert (CDE) Nivel avanzado: threat modeling, IaC security, cadena de suministro. Continuación de CDP.
SANS SEC540 → GIAC GCSA Automatización de seguridad en cloud y CI/CD. El estándar "de oro", pero muy caro (USD 8k+). Suele pagarla la empresa.
EC-Council Certified DevSecOps Engineer (E|CDE) Prácticas DevSecOps a lo largo del ciclo de vida. Existe, pero menos valorada que CDP/CDE o GCSA.

5. AppSec

Certificación Qué acredita Notas
PortSwigger Web Security Academy Labs de vulnerabilidades web (OWASP Top 10 en la práctica). Gratis. No es certificación, pero es el mejor entrenamiento previo.
Burp Suite Certified Practitioner (BSCP) Explotación práctica de aplicaciones web con Burp. Examen práctico. Muy valorada en AppSec.
OffSec OSCP Pentesting práctico de red y sistemas. Opcional y más pesada; solo si querés perfil ofensivo.
OWASP Top 10 / ASVS Referencia de fallos web comunes y checklist de requisitos. No es certificación: es lectura obligada.

Lo que pesa más que el título

En la entrevista técnica y en el día a día, esto vale más que cualquier certificado:

  • Un pipeline propio (GitHub Actions o Jenkins) que integre SAST, SCA y escaneo de secretos y falle el build ante un hallazgo grave.
  • Gestión de secretos con Vault, policy as code (OPA / Kyverno) y firmado de artefactos (Sigstore / cosign).
  • Threat modeling, OWASP Top 10 y nociones de supply chain security (SBOM, SLSA).
  • Scripting en Python / Bash y buen manejo de Git.

El detalle de cada tema está en la página de DevSecOps.
